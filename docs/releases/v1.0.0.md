# checkstBot v1.0.0

## Problem
Learners and researchers lose time manually searching long documents for specific answers. This release provides a practical RAG assistant that ingests common document formats and returns context-grounded responses.

## Core Features
- Multi-format document ingestion (PDF, DOCX, TXT, Markdown)
- RAG chat workflow with semantic retrieval
- Security hardening baseline (CSRF, headers, rate limiting)
- TypeScript strict mode with automated tests
- Recruiter-facing evaluation artifact (`docs/evaluation.md`)
